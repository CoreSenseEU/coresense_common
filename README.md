# CoreSense Common

This repository contains a coresensified <a href="https://github.com/BehaviorTree/BehaviorTree.ROS2">Behaviortree.CPP</a> executor (coresense_bt_controller), common CoreSense messages as well as a bringup package to launch the the BT controller alongside <a href="https://github.com/kas-lab/triplestar_kb" >Triplestar KB</a>, our chosen RDF database wrapper.
